# Implementasi AVL Tree dengan Python

Proyek ini berisi tugas kuliah Struktur Data untuk mengimplementasikan **AVL Tree** (*Self-Balancing Binary Search Tree*) menggunakan bahasa pemrograman Python.

## ✨ Fitur-Fitur
* **Insert & Delete**: Otomatis mencari posisi dan menghapus node.
* **Auto Rebalance**: Melakukan rotasi (*Left/Right Rotate*) agar tinggi pohon tetap seimbang (AVL).
* **Visual Tree Print**: Menampilkan struktur pohon secara horizontal di terminal.

## 🚀 Cara Menjalankan
Cukup jalankan file `AVL Tree.py` menggunakan Python di terminal Anda.
